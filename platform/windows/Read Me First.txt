SynthEdit for Windows (experimental)
====================================

WHAT IS IN HERE

  SynthEdit.exe    the editor - one file, nothing to install
  layouts\         the device descriptions it reads (see "LAYOUTS" below)
  LICENSE          the GNU General Public License, version 3

Extract the whole folder anywhere and double-click SynthEdit.exe. Keep the
"layouts" folder beside it, or choose another one (below). Windows 10 or 11:
the "x64" download for an ordinary PC, "arm64" for Windows on ARM (including
Parallels on an Apple silicon Mac).

THE FIRST RUN - "WINDOWS PROTECTED YOUR PC"

The editor is not signed with a paid certificate, so on the first run Windows
SmartScreen shows "Windows protected your PC". Click "More info", then "Run
anyway". It asks once. If Windows blocked the .zip itself, right-click the .zip
> Properties > tick "Unblock" > OK, before extracting it.

MIDI

SynthEdit uses Windows' own MIDI, so any class-compliant MIDI interface works
with no driver of its own.

SETTING UP

1. Connect both ways: the synth's MIDI OUT to your interface's IN, and the
   interface's OUT to the synth's MIDI IN. SynthEdit reads the synth as well as
   sending to it, so one cable is not enough.
2. Start SynthEdit and choose your synth when it asks (the Device menu
   switches to another one later).
3. Device > MIDI Ports... - choose the input and output the synth is on.
   Leave Channel on Automatic for synths that answer an identity request (Korg
   Z1, Korg Kronos, Novation Supernova II). The Moog Voyager and Minitaur do not
   answer one: set Channel to the channel the synth itself is set to.
4. Press "Sync from synth" to read the current patch. Patch names are read in
   the background once it is connected, and remembered after that
   (File > Clear Patch Name Cache... forgets them).

On the synth itself:

  Korg Z1     Turn System Exclusive Transmit and Receive on (Global > MIDI).
              Leave Program Change Transmit on, so SynthEdit follows program
              changes made on the panel. Turn Memory Protect off before
              storing a patch to a slot.
  Korg Kronos Turn System Exclusive on in its Global MIDI settings.
  Moog Voyager / Minitaur
              Note the MIDI channel it is on, for step 3.

Storing to the synth overwrites a slot in its memory. Back up first:
Backup > Bank (Individual Files)... saves every patch to its own file, and
Restore > Bank (Individual Files)... puts them back.

PARALLELS: pass the MIDI interface to Windows with Devices > USB & Bluetooth,
and choose the interface so it connects to Windows rather than the Mac.

LAYOUTS

SynthEdit does not know about any synth on its own - each one is described by a
plain text file in the "layouts" folder. To edit one, or add one for a synth
nobody has written yet, copy the folder somewhere of your own (your Documents
folder is a good choice), then choose Layouts > Choose Layouts Folder... and
point it there. It is remembered after that.
